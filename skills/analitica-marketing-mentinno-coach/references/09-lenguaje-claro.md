# Módulo 9: lenguaje claro, de la jerga al negocio

Regla: en el chat se habla de decisiones, dinero y clientes. La jerga solo entra si la persona la usa, la pide o está en el anexo técnico.

| Evitar | Decir |
|---|---|
| Correlación de 0,7 | Se mueven juntas con fuerza |
| Coeficiente, beta | Efecto por cada unidad adicional |
| P-valor menor a 0,05 | Es poco probable que sea casualidad |
| P-valor alto | No hay evidencia suficiente de que aporte algo propio |
| Intervalo de confianza 95% | Rango probable |
| R cuadrado | Cuánto del vaivén de tus ventas explica el modelo |
| Poder estadístico, MDE | Qué tan pequeño es el efecto que la prueba puede detectar |
| SRM | El reparto de personas entre grupos no salió como se planeó |
| iROAS | Ventas que el canal agregó de más por cada peso invertido |
| Uplift | A quién le cambia la conducta la acción, no quién compra más |
| Diferencias en diferencias | Cuánto más cambió el grupo con acción que el grupo sin acción |
| Tendencias paralelas | Los dos grupos iban igual antes de la acción |
| CLV, BG/NBD, Gamma-Gamma | Cuánto se espera que compre y gaste un cliente en los próximos meses |
| Markov, Shapley, removal effect | Cuánto cae la compra si quitas el canal del recorrido |
| Atribución último clic | Todo el crédito al canal que cerró |
| Multicolinealidad, VIF alto | Esas variables se mueven casi igual y no se puede separar su efecto |
| Heterocedasticidad | El margen de error cambia según el nivel de ventas |
| Autocorrelación de residuos | El modelo se equivoca de forma repetida en semanas seguidas, le falta algo |
| Overfitting | El modelo memorizó el pasado y no sirve para pronosticar |
| Partición entrenamiento y prueba | Lo probé con datos que no había visto |
| AUC | Capacidad de ordenar bien a quién tiene más probabilidad |
| Calibración | Que el porcentaje que dice coincida con lo que pasa |
| Lift, decil | Cuántas veces más casos que el promedio hay en ese 10% de clientes |
| Precisión y exhaustividad | Cuántos de los que marco son correctos y cuántos de los reales encuentro |
| Fuga de datos | Una columna ya contiene la respuesta |
| Regularización | Un freno para que el modelo no se complique de más |
| Adstock, carryover | Efecto acumulado: el anuncio sigue vendiendo semanas después |
| Saturación, curva de Hill | El siguiente peso rinde menos que el anterior |
| ROI marginal | Lo que rinde el próximo peso invertido |
| Bootstrap | Repetí el cálculo muchas veces con variaciones para ver cuánto cambia |
| Incrementalidad | Ventas que no habrían ocurrido sin la acción |
| Diferencias en diferencias | Comparé cómo cambió el grupo con acción frente a uno parecido sin ella |
| Control sintético | Armé un grupo comparable mezclando zonas parecidas |
| Endogeneidad | La inversión sigue a la demanda, así que parece que la causa |
| Elasticidad | Cuánto cambia el resultado si la palanca sube 1% |
| Cuantiles, quintiles | Grupos del mismo tamaño ordenados de menor a mayor |
| Outlier | Valor muy distinto al resto (puede ser error o caso especial) |
| Sesgo de supervivencia | Solo estoy viendo a quien se quedó |

## Plantillas de frase
- Hallazgo: "[Grupo o canal] aporta [X]% de [resultado] con [Y]% de [inversión o clientes]."
- Rango: "Lo más probable es [valor], con un rango entre [a] y [b]."
- Comparación: "Es [N] veces lo que rinde [alternativa]."
- Confianza: "Puedes decidir con esto, porque [razón]." / "Decide con cautela, porque [razón]."
- Acción: "[Quién] debería [qué] antes del [fecha] para capturar entre [a] y [b]."
- Límite: "Con estos datos puedo mostrar [A]. No puedo afirmar [B] porque [razón]."

## Preguntas de intake sin jerga
- "¿Qué decisión vas a tomar con esto?"
- "¿Qué cifra te dirá si salió bien?"
- "¿Cambiaste algo importante en este periodo (precio, promociones, campañas)?"
- "¿Hubo alguna zona o grupo donde no hicieras la campaña?"
- "¿Prefieres una lectura rápida o un análisis completo que puedas presentar?"

## Estilo en prosa
Oraciones completas y concretas. Sin anunciar el argumento antes de hacerlo. Sin contraste del tipo "no es A, es B". Sin remates de dos a cuatro palabras apiladas. Sin optimismo sin fricción. Sin guiones largos. Sin emojis.
